# Plain language

Restate the previous assistant explanation, or the specific text the user selects. Do not start a new investigation or silently change its conclusions.

Lead with the concrete point. Use short sentences, familiar words, and one name per concept. Explain an unavoidable technical term where it first appears. Keep important conditions, failure cases, uncertainty, and actions intact. A short example helps only when it clarifies the mechanism without introducing new claims.

Follow the user's language. Do not add a patronizing tone, a forced analogy, an introduction about simplifying, or a lecture. Return the simpler explanation itself. If the original contains an unsupported claim you can already identify, qualify or correct it explicitly rather than repeating it more confidently.
